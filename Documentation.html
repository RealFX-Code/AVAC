AvAC's Github repository

Using AvAC on a client

Clients have it easy. Simply get the latest jar (provided by your server administrator) and install it in your QuiltMC client. All important validation gets done on the server, and the client won't have to worry.

Using AvAC on a server

Server hosts have to do a small bit of extra configuration. After the first run a config file should be initialized. (Please see MidnightLib's documentation for finding the config file.) In there you can change the allowed mods.
NOTE: Resource pack checking isn't configurable right now.

Going through the logic

There are two channels registered for this mod:
  1. HIGHLIGHT_PACKET_ID
  2. HANDSHAKE_PACKET
The first channel (HIGHLIGHT_PACKET_ID) is used for the main communication between the Server and Client. The only communication that happens on it, is the client sending the server a list of all installed mods, and all installed resource packs. It's the servers job to then validate them both against the basic checks implemented, and against the allowed-mods list.
The second channel (HANDSHAKE_PACKET) is used to establish with the client that AvAC is both enabled and installed. When a player joins, the server sends a "please respond" packet, and starts a 5-second timer. If the client has responded successfully within those 5 seconds, the player is let in. If not, The client gets disconnected.

The checks that are performed

Resource packs go through a simple check to look for "xray" in their name.
Mods go through a check against a list of "allowed mods", If any mods are detected that aren't on that list, it gets logged to server admins.
Both resource packs and installed mods are logged for each player that joins so server administrators can check what mods and resource packs a player is using.
